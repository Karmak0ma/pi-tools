Card background and purple [subagent] label from option 1. Badges and context bars from option 4. A running task has a spinner in its badge. Each task row shows model, turns, tokens (↑in ↓out) and cost. The line under it shows only the last tool call. No duration (Pi prints it under the tool row).

Sample: same as round 1. explore succeeds, build fails. 96 columns, monokai-vflo.

Notes

  • Context bar = the child's usage.contextTokens divided by its model's context window. Colors match the sidebar: accent ≤ 40%, warning 41–60%, error > 60%. If the window is not known, the bar is hidden and the row keeps its alignment.
  • Header totals are the sum of all tasks (turns, ↑in, ↓out, cost).
  • Collapsed failed task: shows the error line under the last tool call. A successful task shows no output preview when collapsed (Ctrl+O shows the full Markdown answer).
  • Running: fixed height (2 lines per task), so the transcript does not jump while the child streams. Queued tasks show a grey WAIT badge and an empty bar.
  • Also shown: STOP for a task the parent cancelled.
