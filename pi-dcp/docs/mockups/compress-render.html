Shared changes, whichever option you pick

  • Add renderCall: never print raw JSON. Render summary with Pi's Markdown component, so \n becomes real line breaks and lists/code get styled.
  • Collapsed by default; Ctrl+O (Pi's expand key) shows the full summary and recall cues.
  • Multi-range calls: one header line per range in collapsed view; expanded view stacks each range with its own topic.
  • Numbers in text (bright), labels in muted, decoration in dim/border. Today most text uses toolOutput, which is grey in most themes.
  • The model-visible tool result text stays plain and unchanged; only the TUI renderer changes.
